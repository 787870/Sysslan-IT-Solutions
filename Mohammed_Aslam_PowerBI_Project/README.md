# Retail Sales Performance Dashboard 📊

**Author:** A. Mohammed Aslam

## Project Overview
This repository contains a progressive, step-by-step Power BI project completed as part of a Data Analytics internship with Sysslan IT Solutions. The project demonstrates the complete end-to-end workflow of transforming raw retail sales data into an interactive, professional business dashboard.

## Repository Structure & Project Progression

This project is broken down into five distinct phases, documented by the provided `.pbix` files:

*   📄 **`Big_Mart_Sales.csv`**: The raw dataset containing 5,681 rows and 11 columns of product and store-level metrics.
*   📈 **`Level_1_Data_Import.pbix`**: Demonstrates the initial data connection, exploration, and column renaming for clarity.
*   🧹 **`Level_2_Data_Cleaning.pbix`**: Showcases data transformation using Power Query. Includes standardizing inconsistent text values (e.g., 'Fat Content'), managing null values, formatting data types, and utilizing DAX to create calculated total sales columns.
*   📊 **`Level_3_Basic_Visualizations.pbix`**: Features the foundational charts, including clustered bar charts for category performance and column charts for store comparisons.
*   🎛️ **`Level_4_Interactivity_Insights.pbix`**: Adds dynamic functionality through slicers (Product Category, Store Type, Store Size) and Top-N filtering to isolate top-performing products.
*   🚀 **`Level_5_Final_Dashboard.pbix`**: The completed, fully formatted executive dashboard with a cohesive UI/UX design, unified color themes, and active KPI cards.

## Tools & Technologies Used
*   **Business Intelligence:** Power BI Desktop
*   **Data Transformation:** Power Query
*   **Calculations:** DAX (Data Analysis Expressions)

## Key Dashboard Features
*   **Dynamic KPI Cards:** Provides a quick summary of overall Total Sales.
*   **Category Analysis:** Highlights top-performing product groups, identifying "Snack Foods" and "Fruits & Vegetables" as leading drivers.
*   **Store Comparisons:** Visualizes sales performance across different retail outlets.
*   **Top 10 Products:** Utilizes 'Top N' filtering to isolate the highest-grossing individual items.
*   **Interactive Slicers:** Allows users to filter the entire dashboard by specific categories and store parameters to drill down into the data.

## How to View
To interact with the final product, download the `Level_5_Final_Dashboard.pbix` file and open it using Power BI Desktop.
